# Project Ashfall v0.2

**撃って仕込め。縫って断て。**

見下ろしアクション・ローグライト。「射撃で敵に灰紋を刻む → 配置と着地点を見る → SPACEで危険な群れをすり抜ける → 灰を起爆する」が一つの戦闘サイクルです。銃のダメージを積むゲームから、灰の作り方とリープ経路を組み合わせるゲームへ再設計しました。

![命中で敵に灰紋が付き、SPACEの経路が橙に変わる](docs/screenshots/prepared.png)

## 起動

**`Start.bat` をダブルクリック。インストール不要です。** `index.html` をPCブラウザで直接開いても動作します。`index.html`、`game.js`、`style.css` を同じフォルダに置いてください。外部通信、素材、アカウント、有料API、追加フレームワークへの依存はありません。

Node.jsがある場合はフォルダ内で `npm start` を実行し、[localhost:4173](http://localhost:4173) を開けます。終了はCtrl+C。ポートが使用中ならPowerShellで `$env:PORT=4174; npm start` としてlocalhost:4174へ接続してください。

Windows / Chromiumで検証。1280×720以上を推奨し、1024×640の配置も確認しています。タッチ操作・ゲームパッド・途中セーブは未対応です。

## 操作

| 操作 | 入力 |
| --- | --- |
| 移動 | WASD / 矢印 |
| 照準 | マウス |
| 灰を仕込む | 左クリック長押し |
| 自動仕込み切替 | F（照準はマウス） |
| リープで回収・起爆 | SPACEを押す |
| 強化を選ぶ | クリック / 1・2・3 |
| 一時停止・再開 | Esc / P |
| 音声 | M |
| 全画面 | タイトルの「全画面」 |

リープは**移動方向**へ出ます。停止中は**照準方向**です。1回押すごとに1回発動し、長押しで繰り返しません。リープ中と直後の短時間は無敵。ウィンドウを離れると自動休止します。

## 最初の30〜60秒

1. 最初の敵を撃つと、倒す前に橙の灰紋が付きます。灰紋は敵と一緒に移動します。
2. 灰紋の敵を横切る経路は橙になり、終点に `SPACE / 灰の数` が表示されます。
3. SPACEで横切ると灰紋を吸い取り、リープ終了の0.08秒後に軌跡が大きく起爆します。
4. 次の敵に仕込み直します。複数の敵や弾を突破すると、威力・待機時間短縮に加え、耐久を少し回復できます。

**通常移動では灰を取れません。射撃だけでは敵を倒し切れません。灰なしのリープは回避用です。** 青い残火は経験値で、通常移動でも拾えます。緑の十字は回復です。

通常の灰紋は3段階、10秒で薄れ始めます。「濃灰の刻印」で濃く仕込む、「灰の串」で敵列へ通す、「扇に蒔く灰」で横へ広げるなど、同じ周期の中で配置方法を選びます。「零れる灰」を取ると満杯の敵へ命中させて地面にも灰を置けます。この灰もSPACEで回収します。

## ランと記録

既存の通常敵6種類、3分・6分・9分の番人、12分後の炉心を使用しています。最終ボスを倒してクリア。1ラン約12〜16分を想定し、死亡時は早く終わります。

強化は15種類と取り切った後の追加強化。最初の選択は扇状・直線・濃灰の3方式。その後は仕込み、リープ、突破報酬から選びます。衛星は射撃で刻んだ灰紋を増やす役割で、未刻印の敵への仕込みも直接攻撃もしません。

既存の残火印・持ち込み装備の解放は継続します。印や記録はブラウザ保存。ブラウザ・プロファイル・URLを変えると別記録になる場合があります。v0.1の印は引き継ぎ、衛星と銃身の持ち込み効果はv0.2の役割に合わせています。

## 開発と検証

```text
npm test
npm run test:balance
npm run test:browser
```

主要テストはNode.jsだけで動作します。バランス検証は加速した自動プレイヤーです。v0.1との比較はGitの `v0.1-prototype` タグを読み、タグのない配布版では比較のみ省略します。

ブラウザ検証はlocalhost:4173のサーバーと、ポート9223でDevTools接続を受け付けるローカルChromiumを使用します。通常プレイには不要です。ゲーム内5分の実時間入力を含み、約6分かかります。
