# v0.4 — 縫うほど、無茶が通る

v0.3の直線移動・灰回収・予熱・連続炸裂・低音・画面振動・ヒットストップを維持。改善の中心は、攻撃成功を着地後の生存と次の攻撃へ接続することです。

## v0.3からの変更

| 項目 | v0.3 | v0.4 |
| --- | --- | --- |
| 着地の報酬 | 短い無敵、経路上の消弾、小回復 | 灰を回収すると着地点の消弾領域。灰量・対象数で拡大。3体なら長持ち・爆発予告解除・回復4 |
| 待機状態 | 画面端のゲージ、淡い準備完了の輪 | 自機を囲む充填リング、完了時の発光。追加攻撃は緑の二重リングと「もう1回」 |
| 導入 | 開始直後に3体 | 最初の1.6秒は敵なしで自動射撃→照準先に静止した3体→灰紋→橙の経路→左クリック |
| 射撃 | 小さな判定 | 判定半径7、約7度以内の近い照準だけ55%補正。飛翔後の追尾なし |
| 強化 | 主に配置と数値 | 濃灰伝染、貫通＋跳弾の分岐、逆向きの再炸裂、三重縫いから追加攻撃 |
| 後半 | 射手3発、通常敵上限135、最短出現0.28秒 | 射手2発・3.3秒間隔、射手数制限、通常敵上限75・最短0.65秒。番人撃破後4秒の出現休止 |
| 装備 | 一行クリックで順送り | 4択を一覧。効果・ロック・必要な残火印・現在の選択を表示 |

灰なしの回避では着地の消弾を獲得できません。少量でも小さな領域が生まれ、3体の灰紋をまとめると広い安全圏を獲得します。領域は固定地点の短い消弾で、全身の追加無敵ではありません。敵の接触や領域外の爆発には引き続き注意が必要です。予告の薄い円と着地の緑の円が対応します。

初期状態の例：灰1・1体では半径79／0.365秒、灰9・3体では半径203／0.885秒。回復強化で段階ごとに半径+25／持続+0.15秒、回復+4。消弾半径は最大280。敵のHP・ボスの攻撃自体は下げていません。

## 既存強化の組み合わせ確認

| 強化 | 相乗効果・競合への対応 |
| --- | --- |
| 貫通＋跳弾 | 貫通の命中時に別弾を横へ分岐。主弾は直進、枝は残りの跳弾回数を引き継ぐ。同じ敵への再命中を除外し、分岐数も制限 |
| 扇＋貫通／跳弾 | 各弾に双方が乗る。広い敵列へ灰を配れる |
| 濃灰＋仕込み配置 | 満杯の敵から145以内の2〜4体へ伝染。再帰伝染なし、0.8秒間隔。1体を狙って周囲の経路を作る |
| 濃灰＋零れる灰 | 満杯への追撃で伝染と地面配置が併存。地面の灰は次の経路の燃料になる |
| 衛星＋濃灰 | 射撃由来の灰紋を増幅して満杯へ。未刻印の敵には働かず、射撃不要の自動燃料にはしない |
| 二重の縫い目＋長い縫い針 | 0.5秒後に終点から逆走する75%の再炸裂。2段階目は100%と幅1.35倍。元の威力・経路延長が両方へ乗る |
| 返し縫い＋三重縫い | 回収した灰の半分を最大9まで持ち越し、2秒以内に1回追加可能。追加攻撃からは再付与しない。二重の縫い目も追加攻撃に働く |
| 回復＋返し縫い／周期回復 | 消弾拡大と三重縫いの回復。追加攻撃も新しい灰紋3体を横切れば回復できるが、灰の持ち越しだけでは回復しない |
| 減速＋各配置 | 灰紋を経路に留める。仕込みの減速と起爆の減速を保持 |
| 連射＋濃灰／銃身 | 射撃間隔への倍率を合成。下限0.10秒。濃灰の遅さを連射で補える |
| 回収距離＋経路延長 | 灰の回収幅とは別に青い経験値を回収。灰縫いの経験値掃引も継続 |
| 耐久＋回復系 | 最大耐久・即時回復・成功時回復は併存。最大耐久で上限を守る |

強化候補の数・最初の扇／貫通／濃灰の選択は維持。カードには今のビルドとの相乗効果を短く表示し、選択後にも変化を告知します。取り直しが主に数値になる項目も残っています。すべての取得が別の新攻撃になる設計までは広げていません。

## 次の人間のプレイテスト

説明書を渡さず、音ありで最初の5分。続けて番人撃破後と5分以降も観察します。

- 最初の自動射撃を見て「狙うだけ」と理解できるか。最初のクリックが無駄な灰縫いにならず、灰紋から攻撃へ進めるか。
- HUDを見ず、自機の輪から使用可能／待機中／追加攻撃の違いを読めるか。
- 着地の消弾が自分の成功に対する報酬だと分かるか。「3体なら飛び込める」と経路を選び直すか。
- 消弾が終わる前に次の仕込みへ移れるか。番人撃破後の弾幕、接触、爆発に納得できるか。
- 貫通＋跳弾を取った直後、横にも灰が渡ると気付くか。濃灰の伝染が次の灰縫いを誘うか。
- 返し縫いの「もう1回」を使いたくなるか。2秒の判断が忙しすぎないか。追加攻撃と逆向き再炸裂の重なりが強く感じるか。
- 1体への濃い仕込みと3体の広い仕込みの両方を選ぶ余地があるか。守りが強くなりすぎて経路判断が消えていないか。
- 装備4択の効果・ロック・選択中が一目で分かるか。残火印を消費する操作だと誤解しないか。

終了後に「一番気持ちよかった灰縫い」「取得して変化を感じた強化」「理不尽に感じた着地」「次に試したい組み合わせ」を聞きます。自動操作の生存率だけで楽しさやビルドの公平さを判断しません。

## 意図的に変更しなかったこと

マップ、敵の種類、大型ボス、ストーリー、12分の進行、解放装備数、成長・経験値の基本構造、Canvasとローカル音声の構成を維持。射撃の削り上限15%、灰なしの攻撃力0、撃破から無料の灰を出さない制約も継続しました。素材・外部依存は追加していません。

範囲内の敵へ自動的に次々と移動する灰縫いは将来候補のまま。今回の返し縫いは、プレイヤーが再度クリックして選ぶ別の直線です。安全圏の持続延長、ボスの攻撃全体の再設計、ビルド間の大規模調整は人間の結果を待ちます。
