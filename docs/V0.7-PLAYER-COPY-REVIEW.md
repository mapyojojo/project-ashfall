## 全強化の新説明（通常22種＋最終強化）

| 強化名 | 新説明 |

| 扇に蒔く灰 | 仕込み弾が増え、扇状に広がる。横に並ぶ敵へ灰紋を配り、群れをまとめて縫いやすくする。 |
| 灰の串 | 仕込み弾が敵を貫通し、弾速も上がる。奥の敵まで灰紋を付け、一直線にまとめて縫いやすくする。 |

| 灰の伝播 | 灰紋が上限まで溜まった敵への命中で、近くの敵へ灰を分け与える。複数の敵へ仕込みを広げやすくなる。 |
| 長い縫い針 | 灰縫いの距離と、灰紋を回収する幅・炸裂の幅が広がる。奥まで続く敵群をまとめて縫いやすくする。 |
| 広がる灰幕 | 灰紋を回収した着地の消弾範囲が広がり、長く続く。飛んでくる敵弾を消して、次の仕込みを狙いやすくする。 |
| 飛び散る残灰 | 灰縫いの経路上から小さな灰弾が飛び、灰紋に空きのある敵へ灰を付ける。次に縫う敵への仕込みを助ける。 |
| 細い灰雨 | 自動射撃の間隔が短くなる。同じ敵へ素早く灰紋を積み、濃い一撃を準備しやすくする。 |
| 濃灰の刻印 | 1命中で付く灰紋と、敵に蓄えられる灰の上限が増える。少数の敵へ濃く仕込み、高火力の灰縫いを狙いやすくする。 |
| 留める白灰 | 灰縫いの炸裂が当たった敵を減速させる。強敵の動きを抑え、次の仕込みや攻撃を狙いやすくする。 |
| 二重の縫い目 | 灰縫いの経路が、少し遅れて終点から始点へ再び炸裂する。経路上の敵へ追い打ちを狙える。 |
| 密縫いの極意 | 密縫いに成功したときの威力が増す。少数の強敵へ灰を集めるほど、大きな一撃を狙える。 |
| 灰圧 | 1体から新しく回収した灰が6灰以上になると、その敵への炸裂が強くなる。多くの灰を蓄えられる番人や炉心への一撃を伸ばす。 |
| 一点穿ち | 1体から新しい灰紋を6灰以上回収した密縫いで、その敵に追加炸裂する。狙った強敵へ集中して追い打ちをかける。 |
| 返し縫い | 三重縫い後、灰を半分引き継いで2秒以内にもう1回縫える。普段の待機も短くなり、移動速度も上がって攻撃を続けやすい。 |
| 早縫い | 灰縫いで新しく回収した灰の量に応じて、次の待機が短くなる。仕込みを回収し続けると、次の攻撃を早く出せる。 |
| 短針 | 灰縫いの距離と移動時間、基礎の待機が短くなる。近くの敵を小刻みに縫い、次の攻撃へ素早くつなげる。 |
| 連環縫い | 返し縫いで必要な数の敵から新しい灰紋を回収すると、さらに1回縫える。通常・返し縫い・連環縫いの3回をつないで攻め続ける。 |
| 火種の余韻 | 灰を使った灰縫いの後、しばらく耐久が少しずつ回復する。灰縫いを続けると回復を維持し、攻撃しながら立て直せる。 |
| 危地の息継ぎ | 三重縫いか密縫いに成功すると、着地で耐久が回復する。群れをまとめる攻撃や少数への濃い仕込みで、消耗を立て直せる。 |
| 消えない心臓 | 最大耐久が増え、取得時に耐久も回復する。消耗をその場で立て直し、次の被弾に備えられる。 |

| 尽きない残火 | 灰縫いの威力が増し、取得時に耐久が回復する。ほかの強化を育てきった後も、一撃を伸ばせる。 |

## 用語の対応

| 用語 | プレイヤー向けの意味 |
| --- | --- |
| 灰紋 | 敵に蓄えた橙の灰。量を増やす、広げる、回収する対象。 |
| 仕込み | 自動射撃などで敵へ灰紋を付け、次の灰縫いを準備すること。 |
| 灰縫い | 左クリックで経路を直進し、灰紋を回収して軌跡を炸裂させる技。 |
| 三重縫い | 灰紋のある敵を3体以上まとめて縫う成功。広い消弾・待機短縮へ。 |
| 密縫い | 新しい灰紋を1〜2体から合計6灰以上回収する成功。最初から狙える。 |
| 密縫いの極意 | 密縫いに成功したときの威力を伸ばす強化。 |
| 返し縫い | 三重縫いから2秒以内に出す追加の灰縫い。取得が必要。 |
| 連環縫い | 返し縫いで新しい灰紋を必要体数回収した後の、最後の追加1回。取得が必要。 |
| 消弾 | 飛んでくる敵弾を消すこと。地面の予告・範囲攻撃は残る。 |
| 残火 | 青い経験値。集めてLvを上げる。 |
| 残火印 | ランの成果で増える持ち込み装備の解放条件。残火とは別。 |

「伝染」はカードで「伝播」へ、「燃焼帯・爆幅・起爆時」は「炸裂・炸裂幅・炸裂時」へ、「持越し」は「引き継ぐ」へ寄せた。ゲーム内部の識別子・変数名はUIへ出さない。

## 人間が短時間で見るポイント

- 効果を読んで、次にどの敵をどう狙うか想像できるか。
- 灰紋、残火、残火印を混同しないか。
- タイトルから射撃が自動、クリックが灰縫いだと分かるか。
- 最初から狙える成功「密縫い」と、威力を伸ばす強化「密縫いの極意」を区別できるか。
- 三重の3体以上と密の新しい1〜2体・合計6灰以上が伝わるか。
