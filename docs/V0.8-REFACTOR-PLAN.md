# v0.8 構造棚卸しと分離方針

実装前の基準: main / v0.7.1 (`1058b3b1b7d1b884da9b3e24551b843a9d19cb41`)。作業ブランチ: `work/v0.8-i18n-refactor`。

## 現状

- `game.js`（約900行）: ラン状態、乱数、プレイヤー、敵・波・ボス、射撃・灰紋・灰縫い・経験値、Canvas描画、画面遷移、DOM更新、入力、Web Audio、localStorageを管理。
- 入力: 末尾のkeyboard/mouse/blur/visibility/fullscreenイベント。移動の解釈は`movementDirection`、灰縫い要求の消費は戦闘更新内。
- UI: 冒頭の`screen`、タイトル記録・装備・リザルト・強化カード・HUD関数。画面の固定文言は`index.html`。チュートリアル・通知・Canvasの経路ラベルは`game.js`。
- 音声: 冒頭の`tone`/`initAudio`/mute、中央の`stitchNodeSound`/`blastSound`。発音のタイミングは各戦闘処理から呼ぶ。
- 保存: `ashfall.v1`に残火印`marks`、最長`best`、勝利`wins`、ラン数`runs`、選択装備`relic`。装備解放は印数から導出。引退済み装備の番号2を予約し、番号3を維持。
- フルスクリーン: タイトル・ポーズ共通ボタン、Fullscreen API、退出イベントでプレイ中だけポーズ。Pは再開でき、Escは再開しない。
- 強化: `upgrades.js`にID、family、max、apply、requires、excludes、weightと、日本語の名前・説明・Lv詳細・獲得案内・シナジーが同居。
- 装備: `game.js`冒頭の配列に効果と名前・説明が同居。
- `version.js`: ブラウザとNodeで共有するリリース番号。
- 依存: `index.html` → version → upgrades → game。game → DOM/CSS、Canvas、Web Audio、localStorage。NodeのVMハーネスも同じclassic scriptを読む。サーバー不要のfile起動を維持する。

## 分離対象と理由

1. `storage.js`: 既存保存の読書きと独立した言語キー。保存形式を変えず、保存拒否時も起動する。
2. `i18n/ja.js`・`i18n/en.js`・`i18n.js`: 固定/動的文言のキー参照、補間、言語変更通知。表示と戦闘データを分離する。
3. `upgrades.js`・`relics.js`: 数値/効果/IDは維持し、表示は辞書への参照とする。表示getterは既存テスト/利用側との互換性のため残す。
4. `ui.js`: 固定文言、タイトル、ヘルプ、装備、カード、HUD、結果の描画。コールバックでランを参照し、抽選・獲得・記録加算はgameに残す。
5. `audio.js`: Web Audio初期化、mute、SFX生成。発音の呼び出し順と音の乱数源は維持。
6. `input.js`: イベント登録、keyboard/mouse、fullscreen/blur/visibilityの入力連携。ポーズの状態遷移はgameに残す。

## 今回触らない領域

戦闘更新、敵性能/出現、ボス、射撃、ダメージ、灰紋と各縫いの成立条件、装備/強化効果、抽選順/重み、経験値曲線、ラン時間、戦闘乱数、Canvasエフェクトの全面分割。既存IDと装備配列番号、`ashfall.v1`の内容を維持。公開・push・mainへのmerge・itch.io編集はしない。

## 検証方針

既存テストを実装前に実行済み。古いv0.6系コミットをこのcheckoutで取得できない比較はSKIPされるため、今回保存したv0.7.1コミットを必須の比較基準に追加する。戦闘関数の差分、各フレームの状態・将来乱数、6seedの全ラン結果を照合する。両言語の画面、言語保存、旧セーブ、HTTP/file起動、fullscreen/pauseをVMと実ブラウザで確認する。
