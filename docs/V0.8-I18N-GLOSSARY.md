## README / itch.ioとの照合範囲

実装前にREADME、package.json、v0.7公開準備・文言レビュー資料を確認した。READMEは日本語主体で、`package.json`の英文はash/stitch/primeを使い、HUDでは最終ボスを `THE LAST FURNACE` と表記していた。これらとユーザー指定の第一候補に合わせた。

このcheckoutには掲載済みitch.io紹介文の全文・ゲームページURLがない。公開検索でもページを特定できず、掲載済み英文との逐語照合は完了していない。掲載文を確認できた時点でこの用語表と照合する。ページの編集・公開は行っていない。READMEは `Japanese / English` 対応を明記し、掲載文にも転記できる同じ用語の英語案内を追加した。
