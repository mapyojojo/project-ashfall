# v0.5 — 強化の価値と画面の意味を明確にする

v0.4の人間プレイで確認された連続炸裂、返し縫い＋灰紋伝染の連続攻撃、1ランのクリアを出発点にしています。難度曲線を作り直さず、取得した強化が働くことと、不要な文章・曖昧な表示の整理を優先しました。

## 変更内容と判断

| 項目 | v0.4の課題 | v0.5 |
| --- | --- | --- |
| 跳弾 | 選んだ敵の現在位置へ直進し、移動で外れる | 跳弾だけ有限の軌道補正。主弾は直進、貫通時の横への分岐も継続 |
| 強化カード | 次の段階だけの分数表示 | 現在Lv→取得後Lv、各段階の状態と累計効果を併記 |
| 衛星 | 灰紋増幅が高速射撃・伝染と重なる | 強化候補と装備から取り下げ、実行処理と描画も撤去 |
| 着地点の説明 | 慣れた後も毎回表示 | 導入の間だけ文章を表示。経験後は輪・色・矢印・領域予告を維持 |
| 終了統計 | 総討伐と灰縫い討伐がほぼ同じ | 最大同時灰縫い・三重縫い・返し縫い・消した敵弾 |
| HUD | 「縫える」 | READY。追加攻撃は「返し縫い」で用語を合わせる |
| README | 過去の作業ブランチと未merge報告 | 現在の遊び方・仕様・検証方法へ整理 |

## 跳弾の制約

選んだ敵を最大0.38秒だけ追い、毎秒3.2rad・合計0.7rad（約40度）まで旋回します。対象が死亡・命中済みになった場合、または後方90度を越えた場合は補正を終了します。対象を探し直す処理はありません。通常の敵への跳弾開始時の方向転換は既存のままで、その後の移動に小さく追従します。

分岐弾の寿命は親弾の残り時間と0.8秒の小さい方。続く跳弾でも寿命を更新しません。弾速・灰紋量・削りの上限・跳弾回数・同じ敵への再命中除外・分岐数制限を維持しています。貫通の主弾を曲げる処理はありません。

毎秒420の横移動をする走者の場面を、補正あり／なし、貫通あり／なしで比較しました。補正ありは横の敵へ命中し、なしは外れます。貫通ありでは奥の列にも命中します。遠い突進や大きな方向転換では外れる余地を残します。

## 削除した衛星

衛星は半径85の周回接触で、すでに灰紋のある敵へ1灰を足す仕組みでした。未刻印には働かず、満杯への接触も独自の報酬を持ちません。基本射撃間隔0.18秒に対し接触が遅く、仕込み速度と濃灰伝染で代替できます。専用の視覚的な成果も乏しいため、今回は候補から外す判断をしました。

「灰の中継衛星」のカード、装備、プレイヤーの周回数、敵の接触待機、接触増幅、描画、不要なダメージ統計を削除。新しい過熱・糸接続・追撃・灰移送は導入していません。残る通常強化14種類と全取得後の尽きない残火、最初の扇／貫通／濃灰の選択を維持します。

持ち込み装備は3種類です。保存済みの装備番号2だけ旅人の護符へ戻し、残火印・勝利・ラン数・最長記録と装備番号0/1/3を引き継ぎます。割れた銃身の解放条件25印も維持します。

## 各段階の確認

各段階は強化単独の累計を示します。ほかの強化や装備を含むプレイヤーの最終値とは区別します。射撃間隔は倍率と最短0.10秒を記載し、上限を越えて速くなるように見せません。

二重の縫い目Lv2は威力75%→100%と幅1.35倍、濃灰は伝染先2→3→4体、零れる灰Lv2は間隔0.9→0.5秒です。扇・貫通・跳弾は配れる数が増えます。返し縫いLv2/Lv3は追加攻撃を維持して待機を縮める強化で、追加攻撃回数そのものは増やしません。連射・距離幅・耐久・回復など数値中心の段階は残しました。今回はその内容を明示し、別能力への全面改造はしていません。

## 説明を消す境界と統計の定義

説明はランごとに開始し、次のいずれかで着地点の文章、左上の導入、経路説明、地面の灰の回収ヒントを消します。

- 灰のある灰縫いを3回実行した。
- 最初の灰縫い討伐から20秒経過した。
- ラン時刻が180秒に到達した。

灰なしの回避では3回に数えません。一時停止・強化選択中はゲーム内時間と成功数が進みません。導入後も予告の色、経路の矢印、着地点・捕捉敵の輪、消弾半径、充填リング、追加攻撃の二重リングは残します。三重縫い時の長い説明も導入後は「三重縫い」の短い成功表示にします。

| 終了項目 | 集計 |
| --- | --- |
| 最大同時灰縫い | 1回の経路で灰紋を回収した敵の最大数。地面の灰・持ち越し分は敵数に含めない |
| 三重縫い | その経路で新しい灰紋を3体以上回収した回数 |
| 返し縫い | 追加攻撃を実際に開始した回数。付与のみ・期限切れは含めない |
| 消した敵弾 | 経路の消弾と着地領域の吸収の合計。同じ弾を二重計上しない。地面予告は含めない |

v0.4の内部 `bulletsCleared` は着地分だけでした。今回、経路分も加えたため、旧レポートの消弾数との単純比較はできません。

## 次回の人間プレイで確認する点

- 跳弾を取得した直後、動く敵にも灰が渡ると気付くか。貫通の直進と枝分かれを見分けられ、補正が不自然な旋回に見えないか。
- Lv0→1、Lv1→2、Lv2→3を迷わず選べるか。2段階強化の最後と、数値中心の再取得に納得できるか。
- 衛星なしでも選びたい仕込みの候補が十分あるか。3種類の持ち込み装備に選択理由があるか。
- 初回に着地点と消弾を理解できるか。3回／20秒で文章が消えた後も、通常・三重縫い・返し縫いの違いを読めるか。
- 終盤の返し縫い＋伝染による連続攻撃が、v0.4と同じ方向の楽しさを保つか。
- 終了時に自分の最大同時灰縫いと返し縫いを振り返り、次は数を更新したいと思うか。零回の表示も理解できるか。
- 消弾中でも番人・炉心の地面予告を避けると理解できるか。

## 意図的に変更しなかった点

敵の種類・HP・速度・接触火力・敵弾の速度と火力・出現密度・射手上限・ボス攻撃・番人の時刻・12分の進行を維持。灰縫いの距離と時間、予熱と連続炸裂、短い無敵、三重縫いの回復・消弾・待機短縮、返し縫いの持ち越しと連鎖制限、濃灰伝染も維持しています。

衛星削除と跳弾改善は、ビルド選択や灰の配置を通じて結果に影響します。加速比較ではmainの3構成がクリア、v0.5は2構成クリア・地面配置構成が741秒で炉心戦中に死亡しました。この差だけを理由に敵やボスを調整しません。自動操作は正確な経路知識を持つため、公平さや人間の爽快感の証明とは扱いません。

新マップ・敵・ボス・ストーリー・常時追尾の主弾・自動で次々と敵へ移動する灰縫い・新しいメタ進行・外部依存は追加していません。実行済み検証と制約は [TEST-REPORT.md](../TEST-REPORT.md) に記録します。
