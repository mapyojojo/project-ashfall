# v0.1 → v0.2：コアループの違い

| | v0.1 | v0.2 |
| --- | --- | --- |
| 灰の発生 | 敵を倒すと地面に残る | 生きている敵への命中で灰紋を刻む |
| 射撃 | 独立した主攻撃に育つ | 灰の量・配置を作る準備行動 |
| リープ | 回避と追加攻撃 | 灰紋を回収し、戦闘を決着させる主攻撃 |
| 行動の流れ | 撃破 → 灰の場所へ戻る | 仕込む → 配置を読む → 敵群を抜けて起爆 |
| 危険の見返り | 灰の数と一部の強化 | 通過した敵・弾・予告で威力と再使用を強化。複数突破で小回復 |
| ビルド差 | 銃・灰縫い・火球の主攻撃を選ぶ | 濃さ、扇・貫通・跳弾・地面配置、経路、再起爆を組み合わせる |
| 最初の理解 | タイトル・説明書中心 | 生きた敵の灰紋 → 橙の経路予告 → SPACEで吸収と大きな起爆 |

v0.2では、射撃だけでは削りが最大15%で止まり、灰のないリープには攻撃力がありません。通常の撃破から無料の灰も出さず、新たな仕込みを次の周期へ要求します。衛星は直接攻撃から、射撃で刻んだ灰を増やす補助役へ変更しました。未刻印の敵へ衛星だけで仕込むこともできません。

最初の小さな敵群では、敵を倒す前に灰紋と経路が現れます。リープ時だけ色・音・振動・ヒットストップを強めました。回収と爆発の幅を分け、灰紋のある敵を実際に横切ることへ価値を置いています。

既存の1マップ、敵6種類、番人・炉心、12分の構成、軽い持ち込み進行、依存関係なしの起動方式を使用しています。今回の変更はコアの因果関係と伝わり方に集中しています。
