# v0.3 — 灰縫いのプレイフィール実験

## v0.2から変えたこと

| 項目 | v0.2 | v0.3 |
| --- | --- | --- |
| 仕込み | 左クリック長押し／Fで自動化 | カーソル方向へ最初から自動、Fで休止 |
| 灰縫い方向 | 移動方向、停止時のみ照準 | 常にカーソル方向。実行後は終点固定 |
| 主攻撃入力 | SPACE | 左クリック。SPACEは代替 |
| 予告 | 淡い経路と小さい終点 | 始点の輪・矢印・着地点の輪・捕捉敵の輪 |
| 起爆 | 軌跡全体が同時に爆発 | 灰を吸引→予熱→11地点が順に炸裂→白い命中と短い停止 |
| 瞬間表示 | 灰数、通過数、突破表示 | 三重縫いの3体閾値と耐久回復・再使用短縮 |
| 序盤 | 90秒で射手、通常に近い圧力 | 180秒まで射手なし、低密度・低速・被ダメージ軽減。300秒まで射手は単発、通常敵は1体ずつ出現 |

改善したのは操作の予測可能性と攻撃の段階差です。移動しながら狙ってクリックするだけで、仕込みを保ちつつ同じ経路へ灰縫いできます。射撃・灰の生成・主ダメージを別のビルドへ分離していません。三重縫いは「次はもっと巻き込もう」という狙いと、小回復の理由を結び付けます。

## 人間の最初の5分で確認すること

説明書を渡さず、音ありで試します。

- 初回の灰紋を見て、クリックで縫う行動へ自然に進むか。
- WASDを押しながら縫っても、表示した○へ移動すると思えたか。近くをクリックした場合の一定距離が分かるか。
- 起爆は通常射撃より明確に強く感じるか。予熱と連続炸裂は気持ちよいか、遅いか。
- 1体を倒した後、3体をまとめる経路を自分から探すか。緑の予告と回復の対応が分かるか。
- 最初の3分に灰縫いを試す余裕があるか。敵の少なさで待ち時間が長くなっていないか。
- 着地後の敵弾やカメラ移動で迷わないか。音・振動・停止が邪魔になる場面はないか。

自動入力・画像・テストで動作は確認できますが、「縫いたくなる」「繰り返したくなる」はこの観察で判断します。

## 今回変えなかったこと

マップ、敵6種類、番人3体と炉心、12分の進行、既存の強化候補、メタ進行、Canvasとローカル音声の構成を維持。射撃の削り上限15%、灰なしの灰縫いの攻撃力0、撃破から無料の灰を出さない構造も継続。後半を広く再調整する作業はしていません。

## 将来候補（未実装）

「灰縫い中、範囲内の敵を自動的に次々と縫うように移動する」。爽快さを伸ばす可能性はありますが、着地点の予測・経路を選ぶ主体性・自動照準との違いを再検討する必要があります。まず直線型への人間の評価を得てから試します。
